# Writer's Vault

**Персональная среда для писателей** — локальное приложение для работы над книгами с продвинутой разметкой, словарями, управлением персонажами и экспортом.

## О проекте

Writer's Vault — это инструмент для авторов художественной литературы, который помогает структурировать творческий процесс: от первых набросков до финального экспорта. Всё работает локально, без облачных зависимостей — ваши рукописи остаются только у вас.

**Основные принципы:**
- Полная приватность: данные хранятся в локальной SQLite-базе
- Богатая разметка: упоминания персонажей, события, сцены, языковые зоны
- Гибкая структура: серии, акты, главы, сюжетные линии
- Экспорт в DOCX и Markdown с сохранением форматирования

## Возможности

### 📚 Работа с текстом
- **Разметка упоминаний** `[@персонаж]` — автоматическое связывание с досье
- **События** `[#событие]` — создание записей в таймлайне прямо из текста
- **Сцены** `[sc:название]...[/sc]` — структурирование глав
- **Языковые зоны** `[lng]...[/lng]` и `[lang:slug]...[/lang]` — для диалогов на разных языках
- **Форматирование**: `**жирный**`, `*курсив*`, `[size=20]размер[/size]`, `[center]выравнивание[/center]`
- **Автосохранение** каждые 60 секунд (настраивается)
- **Проверка пунктуации и грамматики** в реальном времени

### 👥 Персонажи
- **Досье** с биографией, внешностью, характером, аркой
- **Альбом полароидов** — визуальная галерея персонажей
- **Пробковая доска** — drag & drop для пространственного размещения
- **Полноэкранный режим** для глубокой работы над образом
- **Симметричные связи** между персонажами
- **Состав серии** (премиум) — общие персонажи через несколько книг цикла

### 🌍 Мир книги
- **Словарь** с формами слов и группами (премиум: мультиязычные зоны)
- **Локации** с описаниями и привязкой к главам
- **Таймлайн событий** с автоматическим созданием из меток
- **Лор** — энциклопедия мира с тегами
- **Граф связей** — визуализация отношений между сущностями

### 📖 Структура
- **Серии книг** с общим составом персонажей
- **Акты** внутри книг для трёхактной структуры
- **Сюжетные линии** с битами и связями
- **Сюжетный холст** — визуальное планирование арок

### 🖼 Иллюстрации

- **Коллекция сцены**: изображения с подписью, выравниванием и шириной в карточке сцены
- **Метка `[img:…]`** ставится в курсор премиум-кнопкой редактора через диалог с миниатюрами сцен главы
- **Рендер** в предпросмотре и режиме чтения фигурой с подписью; удаление изображения вычищает его метки из текста
- **Размещение в тексте главы** (`[img:…]` с фигурой в предпросмотре и чтении) — премиум-возможность

### 💾 Резервное копирование
- **Автоматические снимки** при сохранении (не чаще раза в 10 минут)
- **Ручные чекпоинты** кнопкой «Снимок сейчас»
- **Снимок перед удалением** главы — защита от случайностей
- **Бэклог 10 снимков** на книгу с возможностью восстановления

### ☁️ Облачный резерв

- **Детектор клиентов**: кнопка находит установленные Яндекс Диск, Dropbox, OneDrive и Google Drive по стандартным папкам и маркерным файлам
- **Выгрузка пакетов .wvproj** в папку клиента: `latest.wvproj` плюс версионные копии (хранятся последние 5)
- **Ручные папки** для нестандартных расположений и сетевых дисков

### 📤 Экспорт и импорт
- **DOCX** с сохранением форматирования, титульным листом, аннотацией
- **Markdown** с front matter и RFC 5987 для не-ASCII имён
- **Импорт из DOCX** — распознавание глав по стилям
- **Пакет проекта** `.wvproj` — полная выгрузка/загрузка книги

### 🎨 Интерфейс
- **Светлая и тёмная темы**
- **Настраиваемые шрифты** для интерфейса и рукописи
- **Сворачиваемый сайдбар** (рейка 60px ↔ полная панель 280px)
- **Главная страница** с полкой и плиточным видом
- **Профиль автора** со статистикой по всем книгам

## Установка

### Из готового установщика (рекомендуется)

1. Скачайте `Writers-Vault-Setup-X.Y.Z.exe` из [релизов GitHub](https://github.com/your-repo/releases)
2. Запустите установщик
3. Приложение установится в `%LOCALAPPDATA%\Writer's Vault`
4. Данные хранятся в `%APPDATA%\Writer's Vault\dev.db`

### Из исходников (для разработки)

```bash
# Клонировать репозиторий
git clone https://github.com/your-repo/writers-vault.git
cd writers-vault

# Установить зависимости
npm install

# Инициализировать базу данных
npx prisma db push

# Запустить в режиме разработки
npm run dev

Приложение откроется на http://localhost:3000

### Сборка установщика

# Собрать production-версию
npm run build

# Создать установщик для Windows
npm run dist:win

### Использование

# Создание первой книги

1. На главной странице нажмите кнопку + (плюс) на полке или в тулбаре плиточного вида
2. Заполните название, выберите жанр, цвет корешка и стиль
3. При желании добавьте обложку (изображение или первая буква названия)
4. Нажмите «Создать»

# Структура книги

- Паспорт книги — основная информация:
- Название, автор, аннотация, синопсис
- Принадлежность к серии
- Статус: Задумка / В работе / Архив
- Настройки экспорта (титульный лист, метаданные)

# Главы — основной рабочий материал:

- Создавайте главы кнопкой «Новая глава»
- Организуйте в акты через выпадающий список
- Используйте разметку для связей с персонажами и событиями

# Персонажи — досье и связи:

- Откройте вкладку «Персонажи»
- Создайте карточку с базовой информацией
- Заполните детали во вкладках (биография, внешность, характер)
- Используйте [@имя] в тексте для автоматических упоминаний

### Разметка в тексте

Синтаксис               Результат
[@Анна]                 Упоминание персонажа (ссылка на досье)
[#встреча]              Событие (создаётся в таймлайне)
[sc:диалог]...[/sc]     Сцена с названием
[lng]...[/lng]          Общая языковая зона
[lang:elvish]...[/lang] Зона конкретного языка (премиум)
**жирный**              Жирный текст
*курсив*                Курсив
[size=24]...[/size]     Изменение размера
[center]...[/center]    Выравнивание по центру
***                     Разделитель сцен

### Экспорт

# В DOCX:

1. Откройте паспорт книги
2. Настройте галочки: титульный лист, автор, аннотация, синопсис
3. Нажмите «Экспорт в DOCX»
4. Файл откроется в Word/LibreOffice с сохранённым форматированием

# В Markdown:

1. Нажмите «Экспорт в Markdown»
2. Получите .md файл с front matter (название, автор, дата)
3. Подходит для Git, статических генераторов, дальнейшей обработки

### Резервные снимки

# Автоматические:

- Создаются при каждом сохранении главы (с троттлингом 10 минут)
- Всегда создаются перед удалением главы
- Хранятся последние 10 снимков на книгу

# Ручные:

- Кнопка «Снимки книги» в шапке раздела «Главы»
- «Снимок сейчас» — создать контрольную точку
- «Восстановить» — откатить к состоянию снимка
- Восстановление возвращает текст, структуру и пересинхронизирует связи (сцены, упоминания, события).

### Технологии

- Frontend: Next.js 15, React 19, TypeScript
- Styling: Tailwind CSS
- Database: SQLite через Prisma ORM
- Desktop: Electron (опционально)
- Icons: Lucide React
- Export: docx (DOCX), markdown-it (MD)

### Премиум-функции

- Некоторые возможности доступны в премиум-версии (активируется лицензионным ключом):
- Мультиязычные зоны словаря ([lang:slug])
- Состав серии (общие персонажи через книги)
- Расширенные группы словарей
- В режиме разработки (NODE_ENV=development) все функции открыты для тестирования.
- Иллюстрации в тексте главы (метки `[img:…]`, figure-рендер); подключение к облакам по API с двусторонней синхронизацией (готовится)
- Облачный резерв (детектор клиентов и выгрузка пакетов в папки синхронизации)
